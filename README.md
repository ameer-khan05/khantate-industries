# Khanate

The personal operating portfolio of Ameer Khan.

The site presents Ameer's active venture work across product, go-to-market, and
business development, alongside selective advisory services and future writing.

## Active portfolio

- MedVault
- Credexai
- Flip Labs
- Mithara Institute

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```

Production is currently deployed through Vercel from GitHub.
